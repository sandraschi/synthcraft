# `synthcraft-app` (L3 Native egui Synthesizer Studio)

Native pure-Rust desktop studio (`eframe`/`egui` `0.37`) with 14 hierarchical workbenches (37 subpages), 5 hardware skins (including high-contrast Daylight Studio), 4 layouts, GPU-rendered rotary knobs with live modulation rings, 3U Eurorack drag-and-drop patch cables, live `cpal` audio + `midir` MIDI, and searchable `F1` Encyclopedia (`help_docs.rs`).
