# `synthcraft-clap` (CLAP 1.2.2 Instrument Plug-In)

Native CLAP `1.2.2` instrument plug-in (`SynthCraft.clap`, plugin ID `dev.sandraschi.synthcraft`) with embedded hardware GUI (`CLAP_EXT_GUI`), full MPE, and per-note Poly-Mod (`CLAP_EVENT_NOTE_EXPRESSION` + `CLAP_EVENT_PARAM_MOD`). Passes `clap-validator` and is live-verified in **SoundCraft** and **REAPER**.
