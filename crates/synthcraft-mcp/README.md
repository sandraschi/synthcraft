# `synthcraft-mcp` (L2 CLI & 60-Tool MCP Stdio Server)

Dual-mode headless CLI (`--json`) and `MCP 2026-07-28` JSON-RPC `stdio` server exposing 60 synthesis, sequencing, Eurorack patching, WAV rendering, spectral analysis, CLAP host, and DJCraft stem-forge tools (enforcing `--automation-read-root` / `--automation-write-root` sandboxing).
